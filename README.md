# 🥔 DL Potato

An end-to-end Deep Learning project for Potato Disease Classification using TensorFlow, FastAPI, and Streamlit.

## Features

- Potato Disease Classification
- TensorFlow CNN Model
- FastAPI Backend
- Streamlit Frontend
- Docker Support
- Cloud Deployment

## Tech Stack

- Python
- TensorFlow
- FastAPI
- Streamlit
- OpenCV
- Docker
